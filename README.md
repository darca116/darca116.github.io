# ポートフォリオサイト
自身の成果物やスキルをまとめて、就活に役立てるためにポートフォリオサイトを作成しました<br>
大枠はインターネット上で公開されている[テンプレート](https://startbootstrap.com/theme/resume#google_vignette)をもとにし、<br>
細部のカスタマイズ、アレンジはBootStarapのコンポーネントやライブラリを活用しています。<br>
BootStarapを使うのは初めてだったため、[この方](https://qiita.com/oceantako/items/3b88938b0b788c53fcf8)を非常に参考にさせていただきました。<br>
# 使用技術
BootStrap<br>
javascript(jQuery)<br>
github(github pages)<br><br>
BootStrapとjQueryでフロントのみの静的なサイトを作成し<br>
Github Pagesを使って公開しています<br>
